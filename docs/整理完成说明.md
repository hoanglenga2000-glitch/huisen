## 🔐 安全性提升

1. **核心代码保护**：所有业务逻辑代码在 `core/` 目录中，不直接暴露
2. **路由机制**：根目录路由文件只做重定向，不包含业务逻辑
3. **URL保持不变**：用户访问的URL和之前完全一样
4. **文件分类清晰**：工具、文档、核心代码分离

## ⚠️ 注意事项

1. **路径引用**：
   - core目录中的文件使用 `../config/config.php` 和 `../api/`
   - 页面链接使用相对路径（浏览器会自动解析）

2. **访问方式**：
   - 用户访问：`/quotes.php` → 路由文件 → `core/quotes.php`
   - 不要直接访问 `core/` 目录中的文件

3. **API调用**：
   - 前端调用：`api/quotes.php`（相对路径）
   - core目录中调用：`../api/quotes.php`
