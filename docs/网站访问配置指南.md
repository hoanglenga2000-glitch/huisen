# 网站访问配置指南

## ❌ 问题原因

错误 `ERR_NAME_NOT_RESOLVED` 表示浏览器无法解析 `huisen666` 这个域名。

## ✅ 解决方案

### 方案1：配置 hosts 文件（推荐）

1. **以管理员身份打开记事本**
   - 右键点击"记事本" → "以管理员身份运行"

2. **打开 hosts 文件**
   - 文件路径：`C:\Windows\System32\drivers\etc\hosts`
   - 在记事本中：文件 → 打开 → 选择该文件

3. **添加域名映射**
   在文件末尾添加以下行：
   ```
   127.0.0.1    huisen666
   127.0.0.1    localhost
   ```

4. **保存文件**
   - 文件 → 保存

5. **刷新DNS缓存**
   - 按 `Win + R`，输入 `cmd`，回车
   - 在命令提示符中输入：`ipconfig /flushdns`

6. **重启浏览器**
   - 关闭所有浏览器窗口，重新打开

### 方案2：使用 localhost 访问（最简单）

直接使用以下地址访问：

- **首页**：`http://localhost/huisen/index.php`
- **手机首页**：`http://localhost/huisen/core/index_v4.php`
- **产品列表**：`http://localhost/huisen/core/quotes_v6.php`
- **登录页面**：`http://localhost/huisen/login.php`

### 方案3：使用 127.0.0.1 访问

- **首页**：`http://127.0.0.1/huisen/index.php`
- **手机首页**：`http://127.0.0.1/huisen/core/index_v4.php`

## 🔧 检查 XAMPP 服务

确保以下服务正在运行：

1. **打开 XAMPP 控制面板**
2. **检查 Apache 状态**：应该是绿色的"Running"
3. **检查 MySQL 状态**：应该是绿色的"Running"

如果服务未运行，点击对应的"Start"按钮启动。

## 📝 快速访问链接

配置完成后，可以使用以下链接：

- `http://huisen666/index.php` - 官网首页
- `http://huisen666/core/index_v4.php` - 手机首页
- `http://huisen666/core/quotes_v6.php` - 产品列表
- `http://huisen666/login.php` - 登录页面
- `http://huisen666/core/profile.php` - 个人中心（需登录）
- `http://huisen666/core/cart.php` - 询价单

## ⚠️ 注意事项

1. **hosts 文件权限**：必须以管理员身份编辑
2. **DNS 缓存**：修改 hosts 后需要刷新 DNS 缓存
3. **浏览器缓存**：如果还是无法访问，清除浏览器缓存
4. **防火墙**：确保防火墙没有阻止 Apache

## 🐛 故障排查

如果配置后仍无法访问：

1. **检查 Apache 是否运行**
   ```cmd
   netstat -an | findstr :80
   ```
   应该看到 `0.0.0.0:80` 在监听

2. **检查 hosts 文件**
   ```cmd
   type C:\Windows\System32\drivers\etc\hosts
   ```
   确认包含 `127.0.0.1 huisen666`

3. **测试连接**
   ```cmd
   ping huisen666
   ```
   应该返回 `127.0.0.1`

4. **检查项目路径**
   确认项目在 `C:\xampp\htdocs\huisen\`
