## 🔄 迁移步骤

### 阶段1：创建新目录结构
1. 创建 `public/` 目录，移动路由文件
2. 创建 `app/` 目录结构
3. 创建 `assets/` 目录，移动静态资源
4. 创建 `data/` 目录，移动数据文件

### 阶段2：移动文件
1. 移动页面文件到 `app/pages/`
2. 移动组件到 `app/components/`
3. 移动静态资源到 `assets/`
4. 移动数据文件到 `data/`

### 阶段3：更新路径引用
1. 更新所有 `require_once` 路径
2. 更新所有 `href` 和 `src` 路径
3. 更新 API 调用路径
4. 更新配置文件路径

### 阶段4：测试验证
1. 测试所有页面访问
2. 测试所有功能
3. 修复发现的路径问题

## ⚠️ 注意事项
- 保持向后兼容，使用路由文件重定向
- 逐步迁移，确保每一步都能正常运行
- 更新所有路径引用
- 保留旧文件作为备份，直到确认无误
