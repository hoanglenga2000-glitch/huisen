## 🚀 接下来需要做的步骤

### 第一步：确认文件已上传

1. **登录宝塔面板**
2. **进入"文件" → 找到网站根目录**（通常是 `/www/wwwroot/huisen.zhjjq.tech/`）
3. **确认以下文件存在**：
   - `run_image_match.php` - 图片匹配工具
   - `quotes.php` - 报价页面
   - `check_path.php` - 路径诊断工具
   - `config/config.php` - 数据库配置
   - `images/` - 图片目录

### 第二步：配置数据库连接

1. **编辑数据库配置文件**：
   ```
   /www/wwwroot/huisen.zhjjq.tech/config/config.php
   ```

2. **修改数据库连接参数**（根据宝塔面板的数据库配置）：
   ```php
   define('DB_HOST', 'localhost');        // 数据库主机
   define('DB_PORT', '3306');             // 数据库端口
   define('DB_NAME', '甘肃汇森');           // 数据库名
   define('DB_USER', '你的数据库用户名');    // 数据库用户名
   define('DB_PASS', '你的数据库密码');      // 数据库密码
   ```

### 第三步：测试访问图片匹配工具

访问以下URL测试：

```
https://huisen.zhjjq.tech/run_image_match.php
```

或

```
http://huisen.zhjjq.tech/run_image_match.php
```

### 第四步：如果出现404错误

#### 检查1：文件是否存在
- 宝塔面板 → 文件 → 确认 `run_image_match.php` 在网站根目录

#### 检查2：文件权限
- 右键点击文件 → 权限 → 设置为 `644`

#### 检查3：PHP版本
- 宝塔面板 → 网站 → 选择网站 → 设置 → PHP版本
- 确保PHP版本 >= 7.4

#### 检查4：网站运行目录
- 宝塔面板 → 网站 → 选择网站 → 设置 → 网站目录
- 确保运行目录指向项目根目录

### 第五步：使用图片匹配工具

4. **等待匹配完成**（可能需要几分钟）

## 🔧 常见问题排查

### 问题1：访问PHP文件出现404

**解决方案**：
1. 检查文件是否在网站根目录
2. 检查文件权限（644）
3. 检查PHP是否已安装并启用
4. 检查网站运行目录配置

### 问题2：数据库连接失败

**解决方案**：
1. 检查 `config/config.php` 中的数据库配置
2. 确认数据库用户有访问权限
3. 检查数据库是否已创建

### 问题3：图片匹配工具无法访问图片目录

**解决方案**：
1. 检查 `images/` 目录权限（755）
2. 检查图片路径是否正确
3. 确认图片文件存在
