# 快速访问说明

## 🚀 立即访问（无需配置）

如果 `huisen666` 无法访问，请直接使用以下地址：

### 主要页面

1. **官网首页**
   ```
   http://localhost/huisen/index.php
   ```

2. **手机首页（推荐）**
   ```
   http://localhost/huisen/core/index_v4.php
   ```

3. **产品列表**
   ```
   http://localhost/huisen/core/quotes_v6.php
   ```

4. **登录页面**
   ```
   http://localhost/huisen/login.php
   ```

5. **询价单**
   ```
   http://localhost/huisen/core/cart.php
   ```

6. **个人中心（需登录）**
   ```
   http://localhost/huisen/core/profile.php
   ```

## ⚙️ 配置 huisen666 域名（可选）

如果想使用 `http://huisen666/` 访问，需要配置 hosts 文件：

1. 以管理员身份打开记事本
2. 打开：`C:\Windows\System32\drivers\etc\hosts`
3. 添加：`127.0.0.1    huisen666`
4. 保存
5. 运行：`ipconfig /flushdns`
6. 重启浏览器

详细说明请查看：`docs/网站访问配置指南.md`
