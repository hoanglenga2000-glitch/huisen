# 🚀 甘肃汇森网站运行指南

## 📋 快速检查清单

按照以下步骤操作，确保网站能够正常运行：

---

## ✅ 第一步：检查 XAMPP 服务状态

1. **打开 XAMPP 控制面板**
2. **确保以下服务已启动**（显示绿色）：
   - ✅ Apache（Web服务器）
   - ✅ MySQL（数据库服务器）

如果未启动，点击对应的 **Start** 按钮启动服务。

---

## ✅ 第二步：检查数据库是否已导入

### 方法1：使用数据库诊断工具（推荐）

1. 打开浏览器，访问：
   ```
   http://localhost/huisen/check_database.php
   ```

2. 查看诊断结果：
   - ✅ **绿色**：数据库连接成功，表存在且有数据
   - ⚠️ **黄色**：表存在但没有数据
   - ❌ **红色**：表不存在或连接失败

### 方法2：使用 phpMyAdmin 检查

1. 访问：`http://localhost/phpmyadmin`
2. 登录（默认用户名：`root`，密码：空）
3. 查看左侧数据库列表，确认是否有 **`甘肃汇森`** 数据库
4. 点击数据库，查看是否有以下表：
   - `mobile_phones`（手机产品表）
   - `mobile_quotes`（报价表）
   - `phone_details`（产品详情表）

---

## ✅ 第三步：导入数据库（如果未导入）

如果第二步检查发现数据库未导入或数据为空，请执行：

### 使用一键导入工具（最简单）

1. 打开浏览器，访问：
   ```
   http://localhost/huisen/import_database.php
   ```

2. 查看将要导入的 SQL 文件列表
3. 确认数据库配置信息（应与 `config/config.php` 一致）
4. 点击 **"🚀 开始导入数据库"** 按钮
5. 等待导入完成（会显示进度条和日志）
6. 看到 **"✅ 导入完成！"** 后，点击 **"前往报价页面"** 测试

### 手动导入（备选方案）

如果一键导入失败，可以手动导入：

1. 访问：`http://localhost/phpmyadmin`
2. 创建数据库（如果不存在）：
   - 点击 **新建**
   - 数据库名：`甘肃汇森`
   - 排序规则：`utf8mb4_unicode_ci`
   - 点击 **创建**

3. 选择数据库，点击 **导入**
4. 按顺序导入以下 SQL 文件（在 `sql/` 目录下）：
   - `init.sql`（先导入）
   - `phone_details.sql`
   - `update_schema.sql`
   - `insert_phone_data.sql`（产品数据）
   - `upgrade_database.sql`（升级脚本）

---

## ✅ 第四步：运行图片匹配脚本

图片匹配脚本会自动将 `images/图片素材/` 文件夹中的图片匹配到数据库中的手机型号。

### 前提条件

1. **安装 Python 3.7+**（如果未安装）
   - 下载：https://www.python.org/downloads/
   - 安装时勾选 **"Add Python to PATH"**

2. **安装 Python 依赖**
   ```bash
   pip install pymysql
   ```
   或者使用项目根目录的 `requirements.txt`：
   ```bash
   pip install -r requirements.txt
   ```

### 运行脚本

1. **打开 PowerShell 或 CMD**
2. **切换到项目目录**：
   ```powershell
   cd C:\xampp\htdocs\huisen
   ```

3. **运行图片匹配脚本**：
   ```powershell
   python auto_match_images.py
   ```

4. **等待脚本执行完成**（会显示匹配进度和结果）

### 脚本功能说明

- 自动扫描 `images/图片素材/` 文件夹
- 根据品牌和型号名称智能匹配图片
- 更新数据库中的 `image_path` 字段
- 显示匹配统计信息

## ✅ 第六步：常见问题排查

### 问题1：数据库连接失败

**症状**：页面显示"数据库连接失败"

**解决方案**：
1. 检查 XAMPP 中 MySQL 是否启动
2. 检查 `config/config.php` 中的配置：
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', '甘肃汇森');
   define('DB_USER', 'huisen');
   define('DB_PASS', '123456');
   ```
3. 如果用户名密码不对，需要：
   - 在 phpMyAdmin 中创建用户 `huisen`，密码 `123456`
   - 或者修改 `config/config.php` 使用 root 用户

### 问题2：页面显示空白或错误

**解决方案**：
1. 检查 PHP 错误日志：`C:\xampp\apache\logs\error.log`
2. 检查浏览器控制台（F12）是否有 JavaScript 错误
3. 确认 PHP 版本 >= 7.4

### 问题3：图片无法显示

**症状**：产品卡片显示默认占位图或图片404

**解决方案**：
1. 检查 `images/图片素材/` 文件夹是否存在
2. 运行图片匹配脚本：`python auto_match_images.py`
3. 检查图片文件权限（Windows 通常不需要设置）
4. 检查图片路径是否正确（使用 `check_database.php` 查看数据库中的 `image_path` 字段）

### 问题4：报价页面没有产品

**症状**：报价页面显示"暂无数据"或空白

**解决方案**：
1. 使用 `check_database.php` 检查数据库是否有数据
2. 如果没有数据，运行 `import_database.php` 导入数据
3. 检查 `mobile_quotes` 表是否有记录：
   ```sql
   SELECT COUNT(*) FROM mobile_quotes;
   ```

### 问题5：Python 脚本运行失败

**症状**：`python auto_match_images.py` 报错

**解决方案**：
1. 确认 Python 已安装：`python --version`
2. 确认依赖已安装：`pip install pymysql`
3. 检查数据库配置（脚本中的 `DB_CONFIG`）是否正确
4. 确认数据库已创建并导入

## ✅ 第七步：配置域名（可选）

如果需要在局域网内访问或配置域名：

### 局域网访问

1. 查看本机 IP 地址：
   ```powershell
   ipconfig
   ```
   找到 **IPv4 地址**（如：192.168.1.100）

2. 在同一局域网的其他设备访问：
   ```
   http://192.168.1.100/huisen/
   ```

### 配置虚拟主机（推荐）

1. 编辑 `C:\xampp\apache\conf\extra\httpd-vhosts.conf`
2. 添加：
   ```apache
   <VirtualHost *:80>
       ServerName huisen.local
       DocumentRoot "C:/xampp/htdocs/huisen"
       <Directory "C:/xampp/htdocs/huisen">
           Options Indexes FollowSymLinks
           AllowOverride All
           Require all granted
       </Directory>
   </VirtualHost>
   ```

3. 编辑 `C:\Windows\System32\drivers\etc\hosts`，添加：
   ```
   127.0.0.1 huisen.local
   ```

4. 重启 Apache
5. 访问：`http://huisen.local/`
