## 🎯 目录分类说明

### 1. 路由文件（根目录）
- **作用**：作为公开访问入口，保持URL简洁
- **特点**：只做路由重定向，不包含业务逻辑
- **示例**：`/quotes.php` → `core/quotes_v6.php`

### 2. 核心页面（core/）
- **作用**：包含所有业务逻辑的页面文件
- **分类**：
  - 首页：`index_v4.php`
  - 产品：`quotes_v6.php`, `detail_v4.php`, `detail_v5.php`
  - 用户：`login.php`, `register.php`, `profile.php`, `cart.php`
  - 管理：`dashboard.php`

### 3. API接口（api/）
- **作用**：提供JSON格式的API接口
- **特点**：统一使用 `errorResponse()` 和 `successResponse()`
- **路径**：`/api/xxx.php?action=xxx`

### 4. 配置文件（config/）
- **作用**：数据库配置、系统配置
- **特点**：所有页面通过 `require_once '../config/config.php'` 引入

### 5. 静态资源（images/）
- **作用**：存储所有图片资源
- **路径引用**：`../images/xxx` 或 `/images/xxx`

### 6. 数据文件（product_details/）
- **作用**：存储产品详情JSON数据
- **特点**：每个产品一个JSON文件

### 7. 工具脚本（tools/）
- **作用**：数据导入、图片匹配、价格同步等工具
- **特点**：可通过浏览器或命令行访问

## 📝 路径引用规范

### 配置文件引用
```php
// 在 core/ 目录下的文件
require_once '../config/config.php';

// 在 api/ 目录下的文件
require_once __DIR__ . '/../config/config.php';
```

### 图片资源引用
```php
// 相对路径（从 core/ 目录）
<img src="../images/banners/banner_iphone.png">

// 绝对路径
<img src="/images/banners/banner_iphone.png">
```

### API调用
```php
// 从页面调用API
fetch('/api/cart.php?action=add', {...})

// 从API调用其他API
require_once __DIR__ . '/auth.php';
```

### 页面跳转
```php
// 同目录
href="profile.php"

// 上级目录
href="../index_v4.php"

// 绝对路径
href="/core/quotes_v6.php"
```
