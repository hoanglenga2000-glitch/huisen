# 宝塔面板问题排查指南

## 🔍 常见问题及解决方案

### 问题1：访问PHP文件出现404错误

#### 检查步骤：

1. **确认文件确实存在**
   - 宝塔面板 → 文件 → 检查文件是否在 `/www/wwwroot/huisen.zhjjq.com/` 目录下

2. **检查文件权限**
   - 右键点击PHP文件 → 权限
   - PHP文件权限应该设置为：`644`
   - 目录权限应该设置为：`755`

3. **检查网站运行目录**
   - 宝塔面板 → 网站 → 选择 `huisen.zhjjq.com` → 设置 → 网站目录
   - 确保运行目录指向：`/www/wwwroot/huisen.zhjjq.com`
   - 运行目录应该设置为：`/`（根目录）

4. **检查PHP版本**
   - 宝塔面板 → 网站 → 选择网站 → 设置 → PHP版本
   - 确保PHP版本 >= 7.4（推荐7.4或8.0）

5. **检查PHP扩展**
   - 宝塔面板 → 软件商店 → 已安装 → PHP → 设置 → 安装扩展
   - 确保已安装：`pdo_mysql`、`mysqli`、`gd`、`mbstring`

### 问题2：数据库连接失败

#### 检查步骤：

1. **检查数据库配置**
   - 编辑 `/www/wwwroot/huisen.zhjjq.com/config/config.php`
   - 确认数据库连接参数正确

2. **检查数据库是否存在**
   - 宝塔面板 → 数据库 → 查看数据库列表
   - 确认数据库 `甘肃汇森` 已创建

3. **检查数据库用户权限**
   - 宝塔面板 → 数据库 → 查看用户列表
   - 确认用户有访问数据库的权限

### 问题3：图片匹配工具无法访问

#### 检查步骤：

1. **确认文件存在**
   ```
   /www/wwwroot/huisen.zhjjq.com/run_image_match.php
   ```

2. **检查文件权限**
   - 右键点击 `run_image_match.php` → 权限 → 设置为 `644`

3. **检查图片目录权限**
   - 右键点击 `images/` 目录 → 权限 → 设置为 `755`
   - 右键点击 `images/图片素材/` 目录 → 权限 → 设置为 `755`

4. **检查PHP执行时间限制**
   - 如果匹配过程中超时，需要增加PHP执行时间
   - 宝塔面板 → 软件商店 → PHP → 设置 → 配置修改
   - 找到 `max_execution_time`，设置为 `300`（5分钟）

### 问题4：访问时显示空白页面

#### 检查步骤：

1. **检查PHP错误日志**
   - 宝塔面板 → 网站 → 选择网站 → 日志 → 错误日志
   - 查看具体错误信息

2. **开启PHP错误显示**（临时调试用）
   - 编辑 `config/config.php`，确认有以下代码：
   ```php
   error_reporting(E_ALL);
   ini_set('display_errors', 1);
   ```

3. **检查文件编码**
   - 确保PHP文件编码为 `UTF-8`（无BOM）

## 🛠️ 快速修复步骤

### 步骤1：设置文件权限

在宝塔面板文件管理器中：
1. 选中所有PHP文件 → 右键 → 权限
2. 设置为：`644`
3. 选中所有目录 → 右键 → 权限
4. 设置为：`755`

### 步骤2：检查网站配置

1. 宝塔面板 → 网站 → 选择 `huisen.zhjjq.com`
2. 点击"设置"
3. 检查以下配置：
   - **网站目录**：`/www/wwwroot/huisen.zhjjq.com`
   - **运行目录**：`/`（根目录）
   - **PHP版本**：7.4 或 8.0

### 步骤3：测试访问

依次访问以下URL，确认哪个可以正常访问：

1. `https://huisen.zhjjq.tech/` - 首页
2. `https://huisen.zhjjq.tech/quotes.php` - 报价页面
3. `https://huisen.zhjjq.tech/run_image_match.php` - 图片匹配工具
4. `https://huisen.zhjjq.tech/check_path.php` - 路径诊断工具

### 步骤4：查看错误日志

如果仍然失败：
1. 宝塔面板 → 网站 → 选择网站 → 日志 → 错误日志
2. 复制错误信息
3. 根据错误信息进行修复

## 📝 常见错误信息及解决方案

### 错误1：`Call to undefined function`
**原因**：PHP扩展未安装  
**解决**：安装对应的PHP扩展

### 错误2：`Access denied for user`
**原因**：数据库用户名或密码错误  
**解决**：检查 `config/config.php` 中的数据库配置

### 错误3：`No such file or directory`
**原因**：文件路径错误或文件不存在  
**解决**：检查文件路径和文件是否存在

### 错误4：`Maximum execution time exceeded`
**原因**：PHP执行时间超限  
**解决**：增加 `max_execution_time` 值

## 🔧 一键修复脚本

如果以上方法都不行，可以尝试：

1. **重启PHP服务**
   - 宝塔面板 → 软件商店 → PHP → 重启

2. **重启Nginx/Apache**
   - 宝塔面板 → 软件商店 → Nginx/Apache → 重启

3. **清除缓存**
   - 宝塔面板 → 网站 → 选择网站 → 设置 → 伪静态 → 保存（即使不修改）
