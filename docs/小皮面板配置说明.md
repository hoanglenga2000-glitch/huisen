# 小皮面板配置说明 - 解决404问题

## 🔍 问题原因

访问 `localhost/huisen/test.php` 出现404错误，说明**小皮面板的网站目录配置**与文件实际位置不匹配。

## ✅ 解决方案

### 方法1：检查并修改小皮面板网站配置（推荐）

1. **打开小皮面板**
2. **进入"网站" → 选择"localhost" → 点击"设置"**
3. **查看"网站目录"配置**：
   - 如果网站目录是 `C:/xampp/htdocs/huisen`，访问路径应该是：`http://localhost/test.php`
   - 如果网站目录是 `C:/xampp/htdocs`，访问路径应该是：`http://localhost/huisen/test.php`

### 方法2：根据当前配置使用正确的访问路径

#### 情况A：如果网站目录是 `C:/xampp/htdocs/huisen`

访问路径应该是：
```
http://localhost/test.php
http://localhost/quotes.php
http://localhost/run_image_match.php
http://localhost/check_path.php
```

#### 情况B：如果网站目录是 `C:/xampp/htdocs`

访问路径应该是：
```
http://localhost/huisen/test.php
http://localhost/huisen/quotes.php
http://localhost/huisen/run_image_match.php
http://localhost/huisen/check_path.php
```

### 方法3：修改小皮面板配置（永久解决）

1. **打开小皮面板**
2. **网站 → localhost → 设置 → 网站目录**
3. **将网站目录设置为**：`C:/xampp/htdocs/huisen`
4. **保存并重启Apache**
5. **之后访问路径为**：`http://localhost/文件名.php`

## 🧪 测试步骤

1. **先测试根目录文件**：
   - 访问 `http://localhost/index.php`（如果网站目录是htdocs）
   - 或访问 `http://localhost/`（如果网站目录是huisen）

2. **如果根目录能访问，再测试子目录文件**：
   - 根据上面的情况A或B使用正确的路径

3. **如果都不行，检查Apache是否运行**：
   - 小皮面板 → 服务 → 确保Apache显示"运行中"

## 📝 快速诊断

创建一个简单的HTML文件来测试：

访问 `http://localhost/` 或 `http://localhost/huisen/`，看看显示什么：
- 如果显示XAMPP欢迎页面 → 网站目录是 `htdocs`，使用路径B
- 如果显示您的网站首页 → 网站目录是 `huisen`，使用路径A
- 如果显示404 → 检查Apache是否运行，或网站目录配置错误

## 🔧 如果仍然无法解决

1. **检查Apache错误日志**：
   - 小皮面板 → 网站 → localhost → 日志 → 错误日志

2. **检查文件权限**：
   - 确保PHP文件有读取权限

3. **重启Apache服务**：
   - 小皮面板 → 服务 → Apache → 重启
