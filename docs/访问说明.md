# 甘肃汇森网站 - 访问说明

## 🔍 问题诊断

如果您遇到 **404 Not Found** 错误，请按照以下步骤排查：

### 1. 检查Apache服务器状态

- **XAMPP用户：** 打开XAMPP控制面板，确保Apache显示为"Running"（运行中）
- **小皮面板用户：** 检查Apache2.4.39是否显示为运行状态
- **如果Apache无法启动：** 检查端口80是否被占用

### 2. 确认正确的访问路径

根据您的服务器配置，使用以下URL格式：

#### 如果使用标准XAMPP（端口80）：
```
http://localhost/huisen/文件名.php
```

#### 如果使用自定义端口（如8080）：
```
http://localhost:8080/huisen/文件名.php
```

#### 如果使用小皮面板：
```
http://localhost/huisen/文件名.php
```
（小皮面板通常配置localhost在端口80）

### 3. 使用路径诊断工具

访问 `check_path.php` 可以自动检测正确的访问路径：
```
http://localhost/huisen/check_path.php
```
或
```
http://localhost:8080/huisen/check_path.php
```

### 4. 使用工具导航页面

访问 `工具导航.html` 可以快速访问所有工具：
```
http://localhost/huisen/工具导航.html
```

## 🛠️ 常见问题解决

### 问题1：404 Not Found

**原因：**
- Apache未启动
- 文件路径错误
- URL端口号不正确

**解决方法：**
1. 检查Apache是否运行
2. 使用 `check_path.php` 诊断路径
3. 确认URL中的端口号（80或8080）

### 问题2：端口80被占用

**解决方法：**
1. 在XAMPP控制面板中点击Apache的"Config" → "httpd.conf"
2. 找到 `Listen 80` 改为 `Listen 8080`
3. 保存并重启Apache
4. 使用 `http://localhost:8080/huisen/文件名.php` 访问

### 问题3：文件存在但无法访问

**解决方法：**
1. 检查文件权限
2. 检查 `.htaccess` 文件是否阻止访问
3. 检查PHP是否已启用

## 📝 文件位置

所有PHP文件位于：
```
C:\xampp\htdocs\huisen\
```

确保文件确实存在于该目录中。

## 🔗 快速链接

- **工具导航：** `http://localhost/huisen/工具导航.html`
- **路径诊断：** `http://localhost/huisen/check_path.php`
- **报价页面：** `http://localhost/huisen/quotes.php`

## ⚠️ 重要提示

1. **端口号很重要：** 如果Apache配置为8080端口，URL必须包含 `:8080`
2. **子目录路径：** 如果项目在 `huisen` 子目录中，URL必须包含 `/huisen/`
3. **文件扩展名：** PHP文件必须使用 `.php` 扩展名
4. **Apache必须运行：** 所有PHP文件都需要Apache服务器运行才能访问
