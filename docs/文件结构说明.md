## 🔐 安全性说明

### 核心文件保护
- **core/** 目录包含所有控制网站页面的PHP文件
- 实际业务逻辑代码在core目录中，不直接暴露在根目录
- 根目录的路由文件只是简单的重定向，不包含业务逻辑

### 访问方式
- **用户访问**：`http://yoursite.com/quotes.php` → 路由文件 → `core/quotes.php`
- **URL保持不变**：用户看到的URL和之前一样
- **代码受保护**：核心代码在core目录中，更安全

## 📝 文件分类

### 核心页面（core/）
控制网站主要功能的PHP文件：
- `quotes.php` - 报价展示页面
- `detail.php` - 产品详情页面
- `login.php` - 用户登录页面
- `dashboard.php` - 后台管理页面

### API接口（api/）
提供数据接口的PHP文件：
- `quotes.php` - 报价数据API
- `product_detail.php` - 产品详情API
- `auth.php` - 认证API
- `api.php` - 业务数据API
- `match.php` - 智能匹配API

### 工具脚本（tools/）
数据库和图片匹配相关的工具：
- SQL脚本
- 数据导入脚本
- 图片匹配脚本
- 修复脚本

### 文档（docs/）
项目说明文档和部署指南

## ⚠️ 注意事项

1. **路径引用**：core目录中的文件使用相对路径 `../config/config.php` 和 `../api/`
2. **路由文件**：根目录的路由文件保持URL不变，但实际代码在core目录
3. **不要直接访问core目录**：应该通过根目录的路由文件访问
4. **API文件**：已经在api目录中，无需移动

## 🔄 更新路径说明

如果需要在core目录中添加新文件：
- 配置文件：`require_once __DIR__ . '/../config/config.php';`
- API调用：`'../api/quotes.php'`
- 图片资源：`'../images/...'`
