# 项目文件结构说明

## 整理后的目录结构

```
huisen/
├── api/                    # API接口目录
│   ├── api.php
│   ├── auth.php
│   ├── quotes.php
│   ├── product_detail.php
│   └── match.php
│
├── config/                 # 配置文件目录
│   └── config.php
│
├── images/                 # 图片资源目录
│   ├── brands/            # 品牌Logo
│   ├── phones/            # 手机图片
│   └── details/           # 详情图片
│
├── product_details/        # 产品详情JSON数据
│
├── tools/                  # 工具和修复脚本（数据库、图片匹配相关）
│   ├── sql/               # SQL脚本
│   ├── import_price_data.php
│   ├── parse_price_data.php
│   ├── run_image_match.php
│   ├── auto_match_images.py
│   └── ...
│
├── docs/                   # 文档目录
│   ├── 项目结构说明.md
│   ├── 网站运行指南.md
│   └── ...
│
├── index.php              # 网站首页
├── detail.php             # 产品详情页
├── quotes.php             # 报价页
├── login.php              # 登录页
├── dashboard.php          # 后台管理
└── style.css              # 样式文件
```

## 执行整理

1. 在浏览器中访问：`http://localhost/huisen/organize_files.php`
2. 或者手动按照上述列表移动和删除文件

## 注意事项

- 移动文件后，如果代码中有引用这些文件的路径，需要更新路径
- tools/ 目录中的脚本如果需要访问 config/config.php，路径应该是 `../config/config.php`
- 整理完成后，项目结构会更加清晰和专业
