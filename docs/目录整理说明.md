# 目录结构整理说明

## 📁 当前目录结构问题
1. 根目录文件过多，显得混乱
2. 版本文件（v3, v4, v5, v6）混在一起
3. 工具脚本、日志文件散落各处
4. 数据文件和代码文件混在一起

## 🎯 整理方案（保持兼容性）

### 原则
- **保持现有URL路径不变**（通过路由文件）
- **逐步整理，不影响运行**
- **分类清晰，便于维护**

## 🔧 具体整理步骤

### 1. 清理根目录
- 移动 `*.txt`, `*.log` 到 `data/logs/`
- 移动 `*.md` 说明文件到 `docs/`
- 保留必要的路由文件

### 2. 整理 core 目录
- 将版本文件按功能分类
- 保持现有文件名，便于查找

### 3. 整理静态资源
- 移动 `images/` 到 `assets/images/`
- 移动 `style.css` 到 `assets/css/`

### 4. 更新路径引用
- 更新所有 `require_once` 路径
- 更新所有 `href` 和 `src` 路径
- 确保 API 路径正确

## ⚠️ 注意事项
- 所有路由文件保持原位置，确保URL不变
- 逐步迁移，每步都测试
- 保留备份
